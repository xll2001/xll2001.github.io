徐龙龙

我是清华大学计算机科学与技术系博士生，所在实验室为 NetMan Lab，导师为 裴丹教授。我的研究聚焦于LLM 后训练、多模态 LLM 对齐与推理，以及这些技术在长序列数值数据与智能运维中的应用。

我近期主要面向实际数据场景，构建特定任务推理的后训练与评测流程：让模型行为更好地对齐用户意图，通过主动感知和工具调用提升长序列数值数据上的细粒度定位能力，并构建面向垂直领域 LLM 的可靠评测方法。

我于 2023 年获得清华大学计算机科学与技术学士学位，曾在字节跳动、华为、中兴、eBay 和瑞莱智慧进行算法研究实习，产出两篇 ICML 2026 第一作者论文和两篇 CCF A 第一作者在投论文。

经历

围绕 LLM 后训练、多模态推理、智能运维、数值序列预测和故障诊断的工业研究经历。

字节跳动

2025.1 - 2026.6

算法工程师。主要开展三类工作：在异常检测任务的 LLM 后训练方向，通过 Agentic RL 将用户意图与多模态证据转化为更可靠的运维决策；在长序列数值数据多模态 LLM 对齐与推理方向，参与设计并优化原生支持特定模态数据的多模态 LLM；在数值序列预测与基础模型增强方向，解决近期观测捷径依赖与长上下文受限问题。产出：第一作者论文 TameR 与 SPRINT（ICML 2026，CCF A）、两篇 CCF A 第一作者在投论文，以及合作论文 ChatTS（VLDB 2025）与 FoundRoot（ICSE 2026）。

华为

2024.6 - 2024.12

算法工程师。研究光传输网络多源时空表示基础模型 OTN-STFM，联合建模性能指标、告警与拓扑结构，支持异常检测、故障定位与指标劣化感知，在 242 个真实故障案例上实现 91.32% 的根因定位 top-1 准确率，并在内部骨干网系统故障定位任务中完成验证；同时参与 Eagle（FSE 2026）相关工作。
